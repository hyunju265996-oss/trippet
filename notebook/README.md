# PORTFOLIO NOTEBOOK

빈티지 가죽 수첩을 펼쳐 읽는 인터랙티브 포트폴리오. `index.html`을 브라우저로 열면 바로 실행돼요 (인터넷 연결 필요: three.js · 글꼴).
이전 버전(v2)은 `index.v2-backup.html`에 그대로 보존돼 있어요.

## 읽는 흐름 (v3)
**책 넘김 → 종이 확대 → 세로 스크롤 읽기 → 다음 장** 이 자동으로 이어집니다.

1. **랜딩** — 책상 위 버건디 가죽 수첩. `수첩 열기` · 수첩 클릭 · 스크롤 · Enter
2. **펼친 수첩** — `›`를 누르면 오른쪽 종이가 휘어지며 왼쪽으로 넘어감(약 0.8초, 그림자 포함)
3. **자동 확대** — 넘김이 끝나면 방금 넘어간 종이가 그 자리에서 화면 중앙으로 커짐(약 0.64초). 책상·3D 장면은 흐려짐
4. **읽기** — 크림색 종이 안에서 휠 · 트랙패드 · 터치로 세로 스크롤
   - 위: 프로젝트 번호 · 제목 · 한 줄 소개 + 지금 읽는 단계(고정)
   - 왼쪽: 9단계 목차(고정, 현재 단계 강조, 누르면 이동)
   - 아래: 이전 장 · 책으로 돌아가기 · 진행률 · 목차 · 다음 장
5. **다음 장** — 종이가 위로 감기며 책 자리로 축소 → 책장이 넘어감 → 다시 확대 (이전 장도 동일)
6. **전체 목차** — 색 책갈피 탭 + 이름/설명/읽은 정도. 누르면 축소 → 넘김 → 확대로 그 프로젝트로 이동

## 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 다음/이전 장 | → ← · ‹ › · 휠(책 상태) · 책갈피 | 다음 장/이전 장 · 좌우로 밀기 · 위쪽 탭 |
| 읽기(종이 확대) | 넘기면 자동 · 종이 클릭 · Enter | 수첩 열기 시 바로 |
| 책으로 돌아가기 | Esc · 책으로 돌아가기 | — |
| 목차 | T · 목차 | 목차 |

화면 폭 760px 이하에서는 3D 수첩을 줄이지 않고 읽기 중심 화면으로 바뀌어요(책갈피는 가로 탭).

## 내용 고치기
`index.html` 위쪽의 `window.PORTFOLIO`만 고치면 됩니다. 9단계 내용은 프로젝트의 `detail.sections.<단계>.text / images`에,
각 종이(`sheets`)의 소제목은 이름에 따라 해당 단계(문제·조사·인사이트·방향·플로우·와이어·화면/UI)로 자동 배치돼요.
비어 있는 단계는 `[… 입력해 주세요]` 자리 표시가 나와요. 이미지는 `images/`, PDF 이력서는 `files/`에 넣어 주세요.
단계 키: `overview problem research insight direction flow wireframe final result`
