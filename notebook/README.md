# PORTFOLIO NOTEBOOK

빈티지 가죽 수첩을 펼쳐 읽는 인터랙티브 포트폴리오. `index.html`을 브라우저로 열면 바로 실행돼요 (인터넷 연결 필요: three.js · 글꼴).

## 화면
1. **랜딩** — 책상 위 버건디 가죽 수첩(금박 이니셜 · 스티치 · 스냅 스트랩 · 리본). 수첩을 누르거나 `수첩 열기`, 스크롤, Enter로 열기
2. **펼친 수첩** — 오른쪽 종이가 휘어지며 왼쪽으로 넘어감(약 0.8초) · 프로젝트별 색 책갈피 · 하단 ‹ n / N ›
3. **상세 보기** — 가죽 프레임 안의 양피지, 왼쪽 9단계 목차 + 세로 스크롤 본문 + 진행 표시
4. **전체 목차** — 프로젝트별 읽은 페이지 / 진행률 / 완료 체크, 누르면 해당 페이지로 이동

## 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 페이지 넘기기 | ← → · 휠 · 종이 클릭 · ‹ › | 좌우로 밀기 · ‹ › |
| 상세 보기 | D · 종이 두 번 클릭 · 자세히 보기 | 자세히 보기 |
| 목차 | T · 전체 목차 | 목차 |
| 닫기 | Esc · 수첩 닫기 | 닫기 |

화면 폭 760px 이하에서는 3D 수첩 대신 세로 스크롤 **읽기 모드**로 바뀌어요.
